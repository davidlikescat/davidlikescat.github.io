08

Definition

Anthropic이 만든
코딩 에이전트

클로드를 만든 회사 Anthropic의 터미널 기반 AI 코딩 도구입니다. 인터페이스만 낯설 뿐, ChatGPT처럼 대화하면 됩니다. 제작자 보리스의 철학은 분명합니다.

# 터미널에서 ❯ claude # "너는 누구야?" "저는 클로드 코드입니다. 명령줄 인터페이스로 소프트웨어 엔지니어링 작업을 도와드립니다."

"앞으로 모든 코딩은 입코딩(Vibe Coding)이 될 것이다"

09

Installation

설치하는 세 가지 방법

METHOD 1
터미널 / CLI
제작자가 의도한 기본 방식. 터미널을 열고 claude 입력.
METHOD 2
커서 · IDE
Cursor·Antigravity에서 폴더를 열고 내장 터미널로 실행. 실습은 이 방식으로.
METHOD 3 · 가장 쉬움
데스크탑 앱
설치가 어렵다면 Claude 데스크탑 앱 하나로 클로드와 코드를 모두 사용.

설치가 안 되면 꼭 말씀 주세요 — 가능하면 커서로 먼저 들어가 보길 추천

Context Window

Skill vs Sub-Agent

프리랜서 vs 정규직

Skill
프리랜서
작은 단위, 반복 업무
  • 토큰을 적게 소모
  • 가이드라인·스크립트대로 정확히 수행
  • 디자이너·개발자처럼 정해진 일
  • 필요할 때만 꺼내 씀
Sub-Agent
정규직
판단이 필요한 큰 일
  • 독립된 컨텍스트 · 토큰을 많이 먹음
  • 병렬 실행 · 전문 역할 담당
  • 유연하게 대응하는 T자형 인재
  • 서로 소통하며 산출물 생성
