예상 소요 시간 약 15분 · macOS 12 이상
Notion Discord Antigravity Typeless Chrome
시작 전에 — 5가지만 알아두기

맥은 처음이라도
어렵지 않습니다.

아래 5가지만 익히면 어떤 프로그램이든 똑같은 방식으로 설치할 수 있어요. 이 페이지의 모든 설치 과정이 이 원리를 그대로 따릅니다.

1

Safari 여는 법

화면 맨 아래 Dock에서 파란색 나침반 아이콘을 클릭하면 Safari가 열립니다. 맨 위 주소창에 사이트 주소를 입력하고 return 을 누르세요.

2

내 맥 종류 확인 (중요)

왼쪽 위 사과 메뉴 → 이 Mac에 관하여를 클릭. 칩(Chip) 항목에 Apple M1/M2/M3 등이 보이면 Apple Silicon, Intel이라고 적혀 있으면 Intel 맥입니다. 일부 프로그램은 둘 중 맞는 버전을 받아야 해요.

3

다운로드 파일 찾기

다운로드가 끝나면 Safari 오른쪽 위 아래 화살표 아이콘에 표시됩니다. 또는 Dock의 다운로드 폴더(로켓 옆 폴더)에서 방금 받은 파일을 볼 수 있어요.

4

.dmg 설치하는 법

받은 .dmg 파일을 더블클릭하면 창이 하나 뜹니다. 그 안의 앱 아이콘을 옆에 있는 Applications 폴더로 드래그하면 설치 완료. (이게 맥에서 프로그램 설치의 기본 방식이에요.)

5

"확인되지 않은 개발자" 경고

처음 실행할 때 경고가 뜨면 당황하지 마세요. 앱 아이콘을 우클릭(또는 control+클릭) → 열기를 선택하면 됩니다. 그래도 막히면 시스템 설정 → 개인정보 보호 및 보안 맨 아래 "확인 없이 열기"를 누르세요.

+

설치한 앱 실행하기

설치가 끝난 앱은 Dock의 Launchpad(로켓 아이콘)나 Applications 폴더에서 클릭해 실행합니다. 자주 쓰는 앱은 Dock으로 드래그해 고정해두면 편해요.

01 / 05 Notion

메모, 문서, 위키, 할 일까지 한곳에. 우리 팀의 자료와 회의록이 모두 여기 모입니다. 가장 먼저 깔아두세요.

주소창에 입력 notion.com/desktop
1
Safari 주소창에 notion.com/desktop 을 입력하고 return.
2
Download for Mac 버튼을 클릭합니다. (Apple Silicon / Intel을 자동으로 인식해 줘요.)
3
받은 Notion.dmg 를 더블클릭 → Notion 아이콘을 Applications 폴더로 드래그.
4
Launchpad에서 Notion을 실행하고, 회사 이메일로 로그인합니다.
5
로그인 후 팀에서 받은 워크스페이스 초대를 수락하면 자료가 모두 보입니다.
TipApp Store 버전보다 공식 사이트 데스크톱 앱이 기능이 더 완전합니다. 위 경로로 받으세요.
02 / 05 Discord

실시간 소통과 음성 채널의 중심. 팀 채널, 알림, 화면 공유까지 — 슬랙처럼 쓰는 협업 메신저입니다.

주소창에 입력 discord.com/download
1
주소창에 discord.com/download 입력 → Download for Mac 클릭.
2
받은 Discord.dmg 더블클릭 → Discord를 Applications 폴더로 드래그.
3
실행 후 계정 만들기 또는 기존 계정으로 로그인. 회사 이메일을 쓰면 동료 찾기가 편합니다.
4
팀에서 받은 초대 링크를 클릭하면 우리 서버에 바로 입장됩니다.
5
처음 음성 채널에 들어가면 마이크 권한을 묻습니다. 허용을 눌러주세요.
주의음성·화면 공유를 쓰려면 시스템 설정 → 개인정보 보호 및 보안 → 마이크 / 화면 기록에서 Discord를 켜둬야 합니다.
03 / 05 Antigravity

구글이 만든 AI 에이전트 기반 코드 에디터(IDE). AI가 여러 단계의 작업을 알아서 처리해 줍니다. 현재 무료 프리뷰로 쓸 수 있어요.

주소창에 입력 antigravity.google/download
1
주소창에 antigravity.google/download 입력.
2
내 맥에 맞는 버튼을 선택합니다. M1·M2·M3 맥이면 Download for Apple Silicon, Intel 맥이면 Download for Intel. (확인법은 위 "시작 전" 2번 참고)
3
받은 .dmg 더블클릭 → Antigravity를 Applications 폴더로 드래그.
4
실행 시 보안 경고가 뜨면 우클릭 → 열기. 그다음 Google 계정으로 로그인합니다.
5
첫 실행 때 작업 공간과 필요한 구성 요소를 자동으로 내려받습니다. 잠시 기다리면 준비 완료.
참고macOS 12(Monterey) 이상에서 동작합니다. 무료 프리뷰라 사용량 제한이 있을 수 있어요. Gemini 3 Pro, Claude 등 여러 모델을 지원합니다.
04 / 05 Typeless

말하면 글이 되는 AI 음성 받아쓰기. 단순 받아쓰기를 넘어, 다듬어진 문장으로 바꿔줍니다. 타이핑보다 최대 4배 빠르게.

주소창에 입력 typeless.com/downloads
1
주소창에 typeless.com/downloads 입력 → Download for Mac 클릭.
2
받은 .dmg 더블클릭 → Typeless를 Applications 폴더로 드래그.
3
실행 후 마이크 권한과 손쉬운 사용(Accessibility) 권한을 요청합니다. 둘 다 허용 해주세요. (다른 앱에 글을 입력하려면 필요해요.)
4
설정에서 단축키를 확인합니다. 그 키를 누른 채 말하면 어떤 앱에서든 받아쓰기가 됩니다.
5
메모장이나 메신저를 열고 단축키를 눌러 한 문장 말해보세요. 바로 깔끔한 문장이 입력됩니다.
Tip아이폰에서도 쓰려면 App Store에서 "Typeless: AI Voice Keyboard"를 검색해 설치하면 됩니다.
05 / 05 Chrome

가장 널리 쓰는 웹 브라우저. 구글 계정 연동, 확장 프로그램, 개발자 도구까지 — 업무용 사이트가 Chrome에 최적화된 경우가 많습니다.

주소창에 입력 google.com/chrome
1
Safari 주소창에 google.com/chrome 입력.
2
Chrome 다운로드 클릭. 맥 종류(Apple Silicon / Intel)를 묻는 화면이 나오면 내 칩에 맞게 선택하세요.
3
받은 googlechrome.dmg 더블클릭 → Chrome 아이콘을 Applications 폴더로 드래그.
4
Launchpad에서 Chrome 실행. Google 계정으로 로그인하면 북마크·비밀번호가 동기화됩니다.
5
기본 브라우저로 쓰고 싶다면 시스템 설정 → 데스크탑 및 Dock → 기본 웹 브라우저에서 Chrome으로 바꿀 수 있어요.
Tip설치 후 .dmg 창의 디스크 이미지는 데스크톱에서 "추출(eject)" 해 정리해 주면 깔끔합니다. (Notion·Discord 등 모든 .dmg에 동일)

다섯 개, 모두 끝났습니다.

이제 Dock에 다섯 개의 앱이 보이나요? 자주 쓰는 앱은 아이콘을 Dock으로 드래그해 고정해두면 매번 찾을 필요가 없어요.
