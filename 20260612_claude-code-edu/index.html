PROMPT
큰 문제를 잘게 쪼개는 기술

"디스코드 일정 봇 만들어줘"
AI에게 결정권을 너무 많이 넘긴다
에이전틱 접근 — 작은 단위로 분해
01discord.py로 채널 메시지 감시 + 놓친 메시지 캐치업
02텍스트·카톡 캡처를 Claude CLI로 일정 구조화 추출
03날짜를 못 뽑으면 등록 안 하고 디스코드로 되묻기
04Google Calendar MCP로 KST 일정 자동 등록
05SQLite로 중복 등록 방지 (embed↔event 매핑)
06결과 임베드의 버튼·답장으로 수정·삭제
분해가 만든 파이프라인 (002-8)
디스코드 메시지
  ↓
extractor · Claude CLI 일정 추출
  ↓  날짜 검증 — 없으면 되묻기
calendar_client · Calendar MCP 등록
  ↓
state · 중복 방지 ▸ embed 버튼(수정·삭제)
각 단계에서 검증하고 넘어가면, 문제가 생겨도 그 단계(모듈)만 고치면 됩니다 — 디버깅이 훨씬 쉬워집니다.
막연한 한 줄보다, 검증 가능한 여러 단계로. AI는 명확하고 구체적인 지시를 받을 때 최고 성능을 냅니다.
