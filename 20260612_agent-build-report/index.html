시사점 및 제언

1
교육 만족도·추천도 최상위 — 정규 과정화 검토 가치
전반 만족 5.0/5, NPS +100으로 표본 전원이 적극 추천. 비개발 직군 대상에도 "실습 위주" 구성이 주효. 사내 정규 커리큘럼 또는 타 팀 확산 교육으로 편성을 제안.
2
후속 심화 과정 수요 명확 — '멀티 에이전트·연동'
자유 응답에서 멀티 에이전트(3건), Agent 간 연동·오케스트레이션(2건)이 반복 등장. 단발성 에이전트를 넘어선 Session 4(심화) 편성으로 학습 동기를 이어갈 것을 권고.
3
[검토 필요] 내부망 적용 제약 — 실효성의 관건
적용 의향은 100%이나 "내부망에서 사용 불가" 우려가 제기됨. 사내 보안망 내 사용 가능한 환경(승인 도구·온프레미스 대안) 가이드라인을 병행해야 교육 효과가 실제 업무 성과로 전환됨.
4
진입 마찰 완화 — 사전 환경 셋업 지원
응답자 78%가 설치 단계에서 일부 막힘을 경험(모두 해결). 사전 설치 체크리스트·사전 점검 세션을 운영하면 실습 완주율(현 89%)과 자신감 지표(4.67)를 추가 개선 가능.
